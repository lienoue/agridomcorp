    🎓 Plan de test - Élève

    Agriculture 2.0 – Version 1.0 – Septembre 2026

    🎯 Objectif : Vérifier le parcours d'un élève mineur inscrit dans une classe par un enseignant. Il bénéficie du mode Junior et de l'accès Premium via sa classe.

    📋 Informations de test

    ChampValeur
    Profil testéÉlève (mineur en classe)
    Emaileleve.test@example.com
    Mot de passeTest1234!
    Date de naissance01/01/2015 (11 ans)
    Code de classeFourni par l'enseignant (ex: A1B2C3D4)
    Mode Junior✅ Activé automatiquement
    🧒 Rappel : Tout utilisateur mineur a automatiquement mode_junior=True, même sans classe. Mais l'accès Premium est conditionné à son appartenance à une classe.

    🧪 Scénarios de test

    📝 Scénario 1 — Inscription avec code de classe

    • ☐ Aller sur /inscription-eleve/
    • ☐ Remplir : username, email, mot de passe, date de naissance
    • ☐ Saisir le code de classe fourni par l'enseignant
    • ☐ Valider
    • ☐ Attendu : profil Eleve créé
    • ☐ Attendu : profil_eleve.classe rempli
    • ☐ Attendu : mode_junior=True
    • ☐ Attendu : notification envoyée à l'enseignant

    🚫 Scénario 2 — Inscription avec code invalide

    • ☐ S'inscrire avec un code bidon (XXXXXX)
    • ☐ Attendu : message "❌ Code de classe invalide"
    • ☐ Attendu : le compte n'est pas créé

    🎨 Scénario 3 — Mode Junior visuel

    • ☐ Se connecter comme élève
    • ☐ Attendu : thème orange (mode junior)

    • ☐ Attendu : redirection vers dashboard_eleve
