    📝 Scénario 1 — Inscription (mineur seul)

    • ☐ Aller sur /signup/

    • ☐ Attendu : mode_junior=True activé
    • ☐ Attendu : pas de profil Eleve créé

    • ☐ Parent clique sur le lien de validation
    • ☐ Parent remplit ses infos + valide
    • ☐ Attendu : compte activé, mineur peut se connecter

    • ☐ Se connecter comme minjok
