    🧪 Scénarios de test

    📝 Scénario 1 — Inscription

    • ☐ Aller sur la page d'inscription
    • ☐ Remplir le formulaire (username, email, mot de passe, date de naissance)
    • ☐ Valider l'inscription
    • ☐ Attendu : email de confirmation envoyé
    • ☐ Attendu : mode_junior=False (utilisateur majeur)
    • ☐ Attendu : redirection vers le tutoriel
    • ☐ Terminer le tutoriel
    • ☐ Attendu : redirection vers profile

    🏠 Scénario 2 — Dashboard

    • ☐ Aller sur /dashboard/
    • ☐ Attendu : dashboard particulier affiché
    • ☐ Attendu : aucune redirection vers junior
    • ☐ Attendu : météo affichée si parcelle existe

    🌾 Scénario 3 — Créer une parcelle

    • ☐ Cliquer sur "Dessiner une figure"
    • ☐ Dessiner un polygone sur la carte
    • ☐ Nommer la parcelle "Mon potager"
    • ☐ Ajouter une adresse (météo)
    • ☐ Sauvegarder
    • ☐ Attendu : parcelle créée + Parcelle associée automatiquement
    • ☐ Attendu : type de sol assigné (auto ou manuel)

    🌱 Scénario 4 — Ajouter des cultures

    • ☐ Ouvrir la parcelle
    • ☐ Cliquer sur "Modifier les cultures"
    • ☐ Ajouter 3 cultures (tomate, carotte, salade)
    • ☐ Sauvegarder
    • ☐ Attendu : cultures visibles sur la parcelle
    • ☐ Attendu : chronologies créées automatiquement

    📊 Scénario 5 — Quota Gratuit

    • ☐ Créer 3 parcelles au total
    • ☐ Tenter de créer une 4ème parcelle
    • ☐ Attendu : redirection vers limite_parcelles
    • ☐ Attendu : message invitant à passer Premium

    🔒 Scénario 6 — Accès Premium bloqué (Gratuit)
