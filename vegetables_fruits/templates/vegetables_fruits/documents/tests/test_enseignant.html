    🧪 Scénarios de test

    📝 Scénario 1 — Inscription enseignant

    • ☐ Aller sur la page d'inscription
    • ☐ Cocher "Je suis enseignant"
    • ☐ Utiliser un email académique (@ac-paris.fr)
    • ☐ Valider l'inscription
    • ☐ Attendu : is_enseignant=True
    • ☐ Attendu : redirection vers dashboard_enseignant

    🚫 Scénario 2 — Inscription refusée (email non académique)

    • ☐ Créer un compte avec email perso (@gmail.com)
    • ☐ Cocher "Je suis enseignant"
    • ☐ Attendu : message d'erreur
    • ☐ Attendu : inscription refusée

    🏫 Scénario 3 — Créer une classe

    • ☐ Aller sur le tableau de bord
    • ☐ Cliquer sur "Créer une classe"
    • ☐ Nommer la classe "6ème A - Potager"
    • ☐ Valider
    • ☐ Attendu : classe créée avec code unique (ex: A1B2C3D4)
    • ☐ Attendu : visible dans le dashboard

    👨‍🎓 Scénario 4 — Inscrire un élève

    • ☐ Utiliser le code de classe pour inscrire un élève
    • ☐ Attendu : élève créé avec mode_junior=True
    • ☐ Attendu : notification reçue
    • ☐ Attendu : élève visible dans la liste de la classe

    🎯 Scénario 5 — Créer un défi de classe

    • ☐ Aller sur "Défis de classe"
    • ☐ Cliquer sur "Créer un défi"
    • ☐ Type : "planter"
    • ☐ Objectif : 50 plantations
    • ☐ Récompense : 100 points + badge "Jardiniers fous"
    • ☐ Valider
    • ☐ Attendu : défi visible par les élèves

    📊 Scénario 6 — Suivi des élèves

    • ☐ Voir la liste des élèves
    • ☐ Attendu : points et niveaux visibles
    • ☐ Cliquer sur un élève
    • ☐ Attendu : statistiques individuelles
    • ☐ Voir le classement de classe
    • ☐ Attendu : classement correct

    📁 Scénario 7 — Exports

    • ☐ Cliquer sur "Exporter CSV"
    • ☐ Attendu : fichier CSV téléchargé avec élèves
    • ☐ Cliquer sur "Exporter PDF"
    • ☐ Attendu : rapport PDF avec statistiques
    • ☐ Exporter un élève individuellement
    • ☐ Attendu : rapport individuel PDF

    💬 Scénario 8 — Forum école

    • ☐ Aller sur /forum/
    • ☐ Créer un sujet
    • ☐ Épingler un sujet
    • ☐ Fermer un sujet
    • ☐ Attendu : actions fonctionnent

    🛡️ Scénario 9 — Modération

    • ☐ Créer un signalement (via un élève)
    • ☐ Aller sur "Modération"
    • ☐ Attendu : signalement visible
    • ☐ Traiter le signalement
    • ☐ Attendu : message supprimé ou refusé

    📸 Scénario 10 — Modération galerie
