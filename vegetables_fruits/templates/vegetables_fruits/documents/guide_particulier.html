    🌱 Guide utilisateur particulier

    Agriculture 2.0 – Version 2.0 – Septembre 2026

    📌 Introduction

    Agriculture 2.0 est une application web de jardinage pédagogique. Ce guide vous accompagne pas à pas pour utiliser toutes les fonctionnalités, que vous soyez un adulte ou un enfant (mode Junior).

    🔐 1. Créer un compte

    Étape 1 : Accéder au site www.agriculture2.0

    Étape 2 : Cliquer sur "Inscription"

    Étape 3 : Remplir le formulaire (nom, email, mot de passe, date de naissance)

    Étape 4 : Confirmer votre email

    Étape 5 : Suivre le tutoriel de démarrage

    📌 Note : Si vous avez moins de 15 ans, un consentement parental est obligatoire. Si vous avez entre 15 et 17 ans, un email est envoyé à vos parents pour information.

    🌾 2. Créer une parcelle

    Étape 1 : Cliquer sur "Dessiner une figure" dans le menu

    Étape 2 : Choisir le type de parcelle (polygone, cercle, point)

    Étape 3 : Dessiner votre parcelle sur la carte

    Étape 4 : Donner un nom (ex: "Mon potager du fond")

    Étape 5 : Ajouter une adresse (pour la météo locale)

    Étape 6 : Choisir le type de sol (manuel ou automatique)

    Étape 7 : Sauvegarder

    💡 Astuce : Le type de sol automatique est déterminé en fonction de votre localisation (via Mapbox). Idéal si vous ne connaissez pas votre sol !

    🌱 3. Ajouter des cultures

    Étape 1 : Ouvrir votre parcelle

    Étape 2 : Cliquer sur "Modifier les cultures"

    Étape 3 : Parcourir le catalogue (200+ cultures)

    Étape 4 : Cliquer sur une culture pour l'ajouter

    Étape 5 : Une chronologie de culture est créée automatiquement

    Types de cultures disponibles

    • 🥕 Légumes (carottes, tomates, salades, courgettes…)
    • 🍎 Fruits (pommiers, fraisiers, vignes…)
    • 🌺 Fleurs pollinisatrices (78 variétés)
    • 🌿 Aromatiques (basilic, thym, romarin…)

    🧒 15. Abonnement pour un mineur

    ⚠️ Important : Un mineur ne peut pas souscrire directement à un abonnement payant. Il doit obtenir l'autorisation d'un parent.

    Procédure

    Étape 1 : Le mineur va sur sa page Profil

    Étape 2 : Clique sur "Demander l'autorisation d'un parent"

    Étape 3 : Renseigne les informations du parent (nom, prénom, email)

    Étape 4 : Le parent reçoit un email avec un lien unique

    Étape 5 : Le parent valide ou refuse via le lien

    Étape 6 : Si validé → le mineur peut souscrire à l'abonnement

    ⏱️ Validité : L'autorisation parentale est valable 7 jours. Passé ce délai, le mineur doit refaire une demande.
