    👨‍🏫 Guide utilisateur enseignant

    Agriculture 2.0 – Version 2.0 – Septembre 2026

    📌 Introduction

    Ce guide est destiné aux enseignants utilisant Agriculture 2.0 avec leurs élèves. Il vous explique comment créer une classe, gérer vos élèves et utiliser les outils pédagogiques.

    🎉 Bon à savoir : L'abonnement Enseignant inclut toutes les fonctionnalités Premium (bilan carbone, rotation, compagnonnage, statistiques avancées, dashboard climat, prévisions météo 7 jours…) à tarif réduit.

    🔐 1. Créer un compte enseignant

    Étape 1 : Accéder au site www.agriculture2.0

    Étape 2 : Cliquer sur "Inscription"

    Étape 3 : Cocher "Je suis enseignant"

    Étape 4 : Utiliser un email académique (ex: nom@ac-ville.fr, nom@universite.fr, nom@ac.uk)

    Étape 5 : Confirmer votre email

    ⚠️ Important : L'inscription enseignant nécessite une adresse email académique (domaines acceptés : .edu, .ac-, .univ-, .ecole, .lycee, .gouv, .ac.uk, .edu.fr…).

    🏫 2. Créer une classe

    Étape 1 : Une fois connecté, accéder à "Tableau de bord"

    Étape 2 : Cliquer sur "Créer une classe"

    Étape 3 : Donner un nom à la classe (ex: "6ème A - Potager")

    Étape 4 : Un code d'invitation unique est généré automatiquement

    Étape 5 : Partager le code avec vos élèves

    👨‍🎓 3. Inscrire les élèves

    Deux méthodes possibles :

    A. Inscription via le code de classe

    • Communiquez le code aux élèves
    • Les élèves s'inscrivent eux-mêmes via /inscription-eleve/
    • Le profil élève est créé automatiquement
    • Vous recevez une notification à chaque nouvel élève

    B. Création manuelle par l'enseignant

    • Depuis le tableau de bord → "Ajouter un élève"
    • Renseigner les infos (nom, email, classe)
    • Un mot de passe est généré

    📊 4. Tableau de bord enseignant

    Votre tableau de bord affiche :

    • Nombre d'élèves inscrits
    • Points totaux de la classe
    • Liste des élèves avec leurs points et niveaux
    • Signalements forum en attente
    • Notifications récentes

    🎯 5. Créer des défis de classe

    Les défis sont un excellent moyen de motiver vos élèves collectivement.

    Étape 1 : Aller dans "Défis de classe"

    Étape 2 : Cliquer sur "Créer un défi"

    Étape 3 : Choisir le type d'action : planter, récolter, quiz, journal, fleur, connexion, like, commentaire

    Étape 4 : Définir l'objectif (ex: 50 plantations collectives)

    Étape 5 : Définir la récompense (points + badge)

    Étape 6 : Définir les dates (début / fin)

    Étape 7 : Valider → le défi est proposé automatiquement à la classe

    💡 Astuce : Lorsqu'un défi est terminé collectivement, tous les élèves de la classe reçoivent le badge de récompense, pas seulement ceux qui ont participé.

    🏅 6. Suivre les progrès des élèves

    • Liste des élèves : points, niveaux, badges
    • Classement de classe : voir la position de chaque élève
    • Statistiques individuelles : détail par élève
    • Bilan carbone par élève : impact écologique
    • Planification semis par élève : suivi des cultures

    📁 7. Exporter les données

    Export CSV de la classe

    • Tableau de bord → "Exporter CSV"
    • Contient : nom, email, date inscription, points, niveau, badges, mode junior

    Export PDF de la classe

    • Tableau de bord → "Exporter PDF"
    • Rapport complet avec statistiques + tableau

    Export PDF individuel

    • Cliquer sur un élève → "Exporter PDF"
    • Rapport individuel complet

    🛡️ 8. Modérer le forum école

    Étape 1 : Aller dans "Modération"

    Étape 2 : Voir les sujets/messages signalés

    Étape 3 : Choisir une action : accepter (supprime), refuser, sanctionner

    Étape 4 : Vous pouvez aussi :

    • 📌 Épingler un sujet important
    • 🔒 Fermer un sujet
    • 🗑️ Supprimer un message

    📸 9. Valider les photos des élèves

    Les élèves peuvent partager des photos de leur jardin. Vous devez les valider avant publication.

    • Accès : Galerie → "Modération photos"
    • Voir les photos en attente de validation
    • Valider → la photo devient publique
    • Supprimer si non conforme

    🌱 10. Mode Junior de vos élèves

    Tous vos élèves mineurs ont automatiquement mode_junior=True. Cela leur donne :

    • Interface adaptée (couleurs, tutoiement)
    • Points et badges à chaque action
    • Missions hebdomadaires
    • Arbre de compétences
    • Classement de classe

    Vous pouvez désactiver le mode Junior pour un élève spécifique si besoin (élève adulte dans une classe).

    💎 11. Fonctionnalités Premium incluses

    Votre abonnement Enseignant inclut automatiquement :

    • 🌍 Bilan carbone (par parcelle et par élève)
    • 🔄 Rotation des cultures (4 ans)
    • 🌿 Compagnonnage (associations bénéfiques)
    • 📊 Statistiques avancées
    • 🌤️ Dashboard climat consolidé
    • 🌡️ Prévisions météo 7 jours
    • 💧 Plan d'irrigation personnalisé
    • 🎯 Plan de fertilisation
    • 🦠 Gestion des maladies
    • ⚠️ Alertes traitements
    • 📈 Planification des semis

    🔔 13. Notifications enseignant

    Vous recevez des notifications pour :

    • 🎉 Nouvel élève dans une classe
    • ⭐ Élève qui atteint un nouveau niveau
    • 🏆 Classe qui atteint un palier de points
    • ⚠️ Signalement forum

    Les notifications sont visibles dans le menu et peuvent être marquées comme lues.

    🎓 14. Bonnes pratiques pédagogiques

    • Démarrez petit : une parcelle collective avant de passer aux parcelles individuelles
    • Fixez des défis courts : 1-2 semaines max pour maintenir la motivation
    • Valorisez : affichez le classement en classe, félicitez les progrès
    • Alternez : jardinage + quiz + journal pour varier les plaisirs
    • Impliquez les parents : partagez les liens vers la galerie
    • Reliez au programme : SVT, sciences, EMC (écologie, alimentation)
