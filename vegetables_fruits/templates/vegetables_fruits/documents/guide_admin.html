    👨‍💻 Guide administrateur

    Agriculture 2.0 – Version 2.0 – Septembre 2026

    📌 Introduction

    Ce guide est destiné aux administrateurs du site Agriculture 2.0. Il couvre la gestion des utilisateurs, des données et la maintenance du site.

    🔑 1. Accès admin

    URL : /admin/

    Identifiants : Créés lors de la première migration ou via la commande createsuperuser.

    Créer un administrateur

    python manage.py createsuperuser

    👤 2. Gestion des utilisateurs

    Types de profils

    🧒 3. Gestion des utilisateurs mineurs

    Règle automatique

    Règle : Tout utilisateur de moins de 18 ans a automatiquement mode_junior=True, grâce à un signal post_save qui s'exécute à chaque sauvegarde.

    Le signal post_save

    Le signal suivant s'assure que tous les mineurs ont mode_junior=True, quel que soit le chemin de création (formulaire, admin, script) :

    @receiver(post_save, sender=User) def activer_mode_junior_pour_mineurs(sender, instance, created, **kwargs): if not instance.birth_date: return today = date.today() age = today.year - instance.birth_date.year - ( (today.month, today.day) < (instance.birth_date.month, instance.birth_date.day) ) if age < 18: if not instance.mode_junior: User.objects.filter(pk=instance.pk).update(mode_junior=True) instance.mode_junior = True
    💡 À savoir : Le signal ne crée PAS de profil Eleve. Un mineur n'est pas forcément un élève. Le profil Eleve est créé uniquement via inscription_eleve.

    Corriger les mineurs manuellement

    Si un mineur a été créé avant la mise en place du signal :

    # Dans le shell Django from django.contrib.auth import get_user_model User = get_user_model() u = User.objects.get(username='minjok') User.objects.filter(pk=u.pk).update(mode_junior=True) print(f"✅ mode_junior activé pour {u.username}")

    Corriger TOUS les mineurs

    from datetime import date today = date.today() corriges = 0 for u in User.objects.filter(birth_date__isnull=False, mode_junior=False): age = today.year - u.birth_date.year - ( (today.month, today.day) < (u.birth_date.month, u.birth_date.day) ) if age < 18: User.objects.filter(pk=u.pk).update(mode_junior=True) print(f"✅ {u.username} ({age} ans)") corriges += 1 print(f"\n🎉 {corriges} utilisateur(s) corrigé(s)")

    💳 4. Gestion des autorisations parentales

    Modèle AutorisationAchatMineur : autorisation parentale pour permettre à un mineur de souscrire un abonnement payant.

    États possibles

    StatutSignification
    ⏳ en_attenteEmail envoyé au parent, en attente de validation
    ✅ valideeLe parent a donné son accord
    ❌ refuseeLe parent a refusé
    ⌛ expiree7 jours écoulés sans réponse

    Voir les autorisations

    • Admin → Autorisations d'achat (mineurs)
    • Filtrer par statut : en_attente, validee, etc.
    • Voir les preuves légales (IP, user-agent, date)

    Renvoyer un email de validation

    from vegetables_fruits.models import AutorisationAchatMineur aut = AutorisationAchatMineur.objects.get(id=123) # Réinitialiser le token et la date aut.token_validation = '' aut.date_expiration = None aut.save() # Puis cliquer sur "Renvoyer" dans l'admin

    🌱 6. Gestion des cultures

    Ajouter une culture (unités)

    • Admin → Vegetable ou Fruit
    • Cliquer sur "Ajouter"
    • Remplir tous les champs (nom, couleur, saison, prix, conseils...)
    • Sauvegarder

    Ajouter des cultures en masse

    python manage.py shell < ajouter_cultures_rares.py

    Ajouter des fleurs pollinisatrices

    Les 78 fleurs sont gérées directement dans views.py (fonction ajouter_fleur).

    📊 7. Gestion des abonnements

    • Admin → PlanTarification : prix, limites, features
    • Admin → Abonnement : abonnements utilisateurs
    • Admin → Facture : factures Stripe

    Voir un abonnement

    • Utilisateur concerné
    • Plan actif
    • Statut (ACTIF, ESSAI, ANNULE…)
    • Dates (début, fin, prochain paiement)
    • Stripe IDs (customer, subscription)

    📸 8. Modération galerie

    Les photos des élèves sont validées par les enseignants de leur classe. En tant qu'admin, vous pouvez aussi valider ou supprimer :

    • Admin → PhotoJardin
    • Filtrer par est_validee=False
    • Action : cocher est_validee=True

    🛡️ 9. Modération forum

    Deux forums existent :

    • Forum école (élèves + enseignants) → modéré par les enseignants
    • Forum adulte (Basique + Premium) → modéré par les modérateurs

    Voir les signalements

    • Admin → Signalements forum
    • Admin → Signalements forum adulte
    • Filtrer par statut : en_attente, traite, refuse

    🔍 10. Analyse des connexions suspectes

    Le middleware ConnexionLogMiddleware enregistre les connexions pour détecter les abus (multi-IP, multi-appareils).

    Consulter les logs

    • URL : /analyse-connexions/ (réservé is_staff)
    • Voir les utilisateurs avec plusieurs IP
    • Voir les connexions suspectes
    • Statistiques globales

    🛠️ 11. Maintenance

    Sauvegarde de la base

    python manage.py dumpdata > sauvegarde.json

    Restaurer une sauvegarde

    python manage.py loaddata sauvegarde.json

    Réinitialiser complètement

    ⚠️ DANGER : Cette commande supprime TOUTES les données. À utiliser uniquement en développement.
    python manage.py flush

    Migrations

    python manage.py makemigrations python manage.py migrate

    Fichiers statiques

    python manage.py collectstatic --noinput
